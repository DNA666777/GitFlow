# GitFlow for VS Code

The **standard Gitflow** ([Atlassian Gitflow Workflow](https://www.atlassian.com/git/tutorials/comparing-workflows/gitflow-workflow)) without leaving VS Code: start and finish `feature/`, `release/` and `hotfix/` branches, with local merge or Pull Requests on GitHub and Azure DevOps.

> **Preview, under construction.** This version only starts the GitFlow engine and shows the repository state (*GitFlow: Show Repository State*). The commands, the GitFlow view and the Pull Request mode come next.

The same engine as the [GitFlow extension for Visual Studio](https://marketplace.visualstudio.com/items?itemName=DNA666777.gitflow), so both editors behave exactly the same way.

## Requirements

- Git on the PATH.
- The .NET 8 runtime is provided automatically by the **.NET Install Tool** extension (installed with this extension). To use another `dotnet`, set `gitflow.dotnetPath`.

## Languages

English and French, following the VS Code display language.
